Algoritmos e Estruturas de Dados II:
Trabalho 1 

Robôs formam uma longa LINHA numerados de 0 a n-1 e trocam de posição de acordo com uma "RECEITA" de dança pelo robô-mestre
Os robôs tem que trocar de posição MUITAS VEZES até que a linha de robôs repita alguma linha que já tenha sido dançada

Propostas de "RECEITA":
Inicia-se com n robôs;
Depois se organizam em alguma ordem 0 até n-1
[Exemplo: (7 robôs) 
7
5-6-0-4-2-3-1]
Isso mostra que TODO robô na SEXTA posição irá para posição 0 na próxima rodada, o robô na SÉTIMA posição vai para a PRIMEIRA posição, o robô que estava na posição 0 vai para o SEGUNDO lugar, o robô da PRIMEIRA posição vai para a SÉTIMA, o robô da TERCEIRA vai para a SEXTA posição, o robô da SEGUNDA posição vai para a QUARTA, o robô da QUARTA posição vai para a TERCEIRA. A dança repete sempre os mesmos movimentos.
*Se essa receita for implementada:

4 6 3 0 5 2 1
